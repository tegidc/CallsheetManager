The observation: Oswald is carrying 24 rules across 4 sizes, 3 weights and 6 different letter-spacings. It started as the brand's utility font for small uppercase labels and has spread into tabs, pills, badges, column headers and controls — each with slightly different settings. Right now: Fraunces = display headings, Oswald = anything small and uppercase, Jost = everything else. The roles are clear, but Oswald's territory is very wide.

Current: desktop uses the native checkbox with accent-color:var(--tape), so checking it fills the box solid green with a white tick. What kind of secondary colour do you actually want?

These are two different problems wearing the same hat: a technical one (green is unreadable on the dark sidebar) and a design one (there's no way to mark a second category). A solves the first, B solves the second, C solves both.

If you want a warm second hue, which?

Amber #B07A2E, ochre #8C6A3F, or clay #7A4B2A — or name something else. Note the existing --danger is a red #a4321f, so a warm secondary needs to stay clearly distinct from it.
