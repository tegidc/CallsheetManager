Style Audit
A diagnostic catalogue of every visual style decision currently in use across the app — for review, not a feature. Nothing here is live project data.
How to use this page: each section groups elements that serve the same purpose in the app so you can compare how differently they currently render. Every example is labelled with its MAP.md section code (e.g. T-2, D-1.3) and its real CSS class name, so feedback here (“keep the T-5.2 style, drop the T-2 one”, “pick candidate icon X for the Y slot”) maps directly back to a specific piece of code for the follow-up unification pass. This page makes no changes to index.html or the live app.

04
Component behaviors
Every place an Expand-all / Collapse-all (or similar toggle) pattern exists, shown side by side with its current markup.
Four separate implementations of “expand/collapse everything” exist in the app today, each with its own markup, state model and visual affordance. Three are driven by the shared expandCollapseAllHTML() helper but still render as two always-visible text links; the fourth (Phase V, the Crew tab) was deliberately rebuilt as a single rotating-chevron toggle and never back-ported to the other three.
Pattern 1 — Two separate text links (via shared expandCollapseAllHTML() helper)
Used identically in three places: T-4 Tech tab (+ a "Summary" jump-link appended), T-6 Preview & Export, and D-1 Crew database dept groups (+ T-5 Shoot Days, same call with no extra link). Renders two always-visible spans; clicking either one always does the same thing (open everything / close everything) regardless of current state.
T-4 Tech tab / T-6 Preview / D-1 Crew DB / T-5 Shoot Days
Expand all · Collapse all · Summary
markup: <div class="dept-toggle-all"> · two independent onclick handlers, one per direction · text-only, no icon · right-aligned, 11px muted
Pattern 2 — Single rotating-chevron toggle (Phase V, Crew tab only) DIVERGES
Rebuilt for T-2 (all five Crew view-switcher tabs: Roles/Days/Hotel/Travel/Catering) as a single control that flips its own label and rotates a caret 180°, embedded in the wider .crew-header-row alongside Select all and Filter. Confirmed direction for Phase V was this pattern everywhere — not yet applied to Tech/Preview/Crew-DB/Shoot-Days above.
T-2 Crew tab (Roles / Days on site / Hotel / Travel / Catering)
 Select all ▾ Filter
▾ All Summary
markup: <span class="crew-header-expandall"> inside .crew-header-row · single onclick, flips based on current state · chevron icon rotates 180° · word "All" · same row as Select all/Filter/Summary
Pattern 3 — Per-item collapse caret (not an "all" toggle, but the same underlying affordance rendered two more ways)
Individual section/group headers each carry their own expand/collapse caret — shown here because any unification of the "all" toggle above should probably also settle on one of these two caret styles for consistency.
